# Brgy Putatan Appointment System


A simple **VB.NET Windows Forms Brgy Putatan Appointment System** built with Visual Studio. This project demonstrates user authentication, password management, and basic user account administration.

## Features

* User Login
* Change Password
* Forgot Password
* Create User Account
* User Information Management
* Windows Forms Interface
* VB.NET Source Code

## Technologies Used

* VB.NET (.NET Framework)
* Windows Forms
* Visual Studio
* App.config Configuration

## Project Structure

```

└── ...
```

## Getting Started

1. Clone the repository:

```bash
[git clone https://github.com/your-username/LoginSystem.git
```](https://github.com/mjudielmeguiel/LoginSystem.git)

2. Open `LoginSystem.vbproj` in Visual Studio.
3. Restore any required dependencies.
4. Build and run the project.

## Requirements

* Visual Studio 2022 or later
* .NET Framework compatible with the project
* Windows 10/11 OS

## Manual

1. Create New ADMIN Account
2. Sign in your ADMIN Account
3. Show your Dashboard Recent Active users, Lock and Inside your Department Users
